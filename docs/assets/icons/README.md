# Icon Assets

Place game icons in these folders. All images should be PNG format.

## difficulty/
- `easy.png` — Easy mode icon (green/nature theme)
- `normal.png` — Normal mode icon (balanced/gold theme)
- `hard.png` — Hard mode icon (fire/orange theme)
- `insane.png` — Insane mode icon (skull/red theme)
